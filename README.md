# Hi, I'm Harrison 👋

I live in Malmö, Sweden, and I write code mostly for fun these days: tabletop RPG tools, DJ library plumbing, and the occasional gadget hack.

## Things I've built

**Stars Without Number tools**
- [swn-go](https://github.com/nhr/swn-go): Go port of my sector generator for Kevin Crawford's *Stars Without Number*
- [swn-revised-go](https://github.com/nhr/swn-revised-go): the same idea, for the Revised Edition
- [swn](https://github.com/nhr/swn): the original Perl version (archived, but 60 people starred it, which still delights me)

**Music**
- [music-tools](https://github.com/nhr/music-tools): Ruby scripts for keeping a DJ library in order

**Gadgets**
- [kobo-literary-clock](https://github.com/nhr/kobo-literary-clock): turns a Kobo e-reader into a clock that tells time with quotes from books
